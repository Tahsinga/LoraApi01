How to restore a branch

On the branch PC, after reinstalling Windows / Quantum.

  1. Install Quantum POS and create its database as normal. Don't start the Lora branch sync (POSViewer) yet.
  2. Click Download restore script for that branch above and copy the .sql file to the branch PC.
  3. Open it in SQL Server Management Studio, select the branch's Quantum database at the top, and press Execute. The first run is a dry run: it shows how many products and stock rows it would restore and saves nothing.
  4. If the numbers look right, change @Apply = 0 to @Apply = 1 near the top and press Execute again.
  5. Start POSViewer with the same branch name. Stock transfers still queued on the website are applied by the sync as usual.
The backup is the stock as of the branch's last sync (shown in the table). Sales made after that and never synced cannot be recovered. Running the script again is safe: stock is set to the backed-up value, never added on top.

If the website is down

The Main computer keeps its own copy of every branch's products and stock (CloudPOS database, dbo.BranchProductCatalog).

  1. Download Main computer script now and keep a copy on the Main computer.
  2. Open it and set @Branch to the branch name.
  3. On the Main computer run:
    sqlcmd -S .\SQLEXPRESS -E -d CloudPOS -i restore_branch_from_main.sql -o restore_BRANCH.sql
    (or run it in Management Studio and copy the Messages tab into a file).
  4. The output is the same restore script as the website gives: run it on the branch PC as described on the left.
Change .\SQLEXPRESS and CloudPOS if the Main computer uses another SQL Server instance or database name.
